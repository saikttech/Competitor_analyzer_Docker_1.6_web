RAG Competitor Analyzer

Автоматизированный AI-пайплайн для глубокого анализа конкурентов с генерацией PDF-отчётов

Автор: Сергей Дмитриев

2026

🎯 Проблема

  • ⏳ Потеря времени: Ручной анализ конкурентов занимает часы (поиск, чтение, структурирование).
  • 🧠 Субъективность: Высокий риск упущения важных деталей и человеческий фактор.
  • 💸 Дорогие аналоги: Существующие решения либо слишком дороги, либо не адаптированы под специфические ниши.

💡 Наше решение

Система, которая за ~30 секунд самостоятельно находит конкурентов, парсит их сайты и генерирует структурированный бизнес-отчёт.

Запрос (Ниша + Гео + Детали)

🏗 Архитектура системы

🎨 Frontend: Streamlit
⚙️ Backend: FastAPI + Celery + Redis
🤖 AI: OpenAI (ProxyAPI) + Serper.dev
🗄️ Data: PostgreSQL (pgvector)

⚙️ Этапы RAG-пайплайна

  1. 🔍 Поиск: Каскадный поиск (Serper.dev → DuckDuckGo → Fallback).
  2. 🕷️ Парсинг: Умная очистка HTML с обходом защиты через curl-cffi.
  3. 🧠 Анализ: Отправка очищенных данных в LLM со строгим системным промтом.
  4. 📄 Экспорт: Рендеринг отчёта в PDF с полной поддержкой кириллицы.

🛡️ Инженерные вызовы и решения

❌ Блокировки поисковиков (403, Ratelimit)

✅ Решение: Переход на стабильный Serper.dev (Google Search API).

❌ Блокировки парсинга (HTTP 403)

✅ Решение: Использование curl-cffi с подменой TLS-отпечатка под Chrome 110.

❌ Галлюцинации LLM (выдумка конкурентов)

✅ Решение: Жёсткий системный промт + снижение temperature до 0.2.

❌ Квадратики (■■■■) вместо русского текста в PDF

✅ Решение: Программная регистрация шрифтов DejaVu Sans через ReportLab.

📊 Демонстрация результата

Система выдает релевантные, а не выдуманные данные.

Пример из отчёта по нише "Кофейни с веганскими десертами":

"На рынке кофеен в Москве существует конкуренция... Найдены реальные конкуренты: Циники (веганское кафе с двумя точками в Москве, разнообразное веганское меню)."

✅ Никаких выдуманных компаний или нерелевантных данных (вроде аренды автомобилей).
